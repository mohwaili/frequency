# Frequency

Releases of Frequency, a menu-bar dictation app for Apple Silicon Macs running
macOS 15 or later.

Download the latest `.dmg` from the [Releases](../../releases) page, open it,
and drag Frequency to Applications.

Installed copies check [`appcast.xml`](https://mohwaili.github.io/frequency/appcast.xml)
for newer versions. That address is permanent: every copy in the field checks it
forever, so it is never moved.
